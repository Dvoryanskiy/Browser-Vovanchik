# Vovanium — полная документация

Браузер на **Electron** (Chromium) с вкладками, адресной строкой и встроенным **AI-ассистентом** через OpenAI-совместимый API (DeepSeek и другие провайдеры).

## 1. Требования и установка

### Системные требования

- **ОС:** Windows 10/11 (основная целевая платформа), также подойдут macOS и Linux при наличии Node.js.
- **Node.js:** актуальная LTS или Current (рекомендуется с [nodejs.org](https://nodejs.org/)).
- **npm:** идёт вместе с Node.js.

### Установка зависимостей

В каталоге проекта:

```bash
cd c:\Users\Ivan\my-browser
npm install
```

Устанавливается **Electron** как `devDependency` (см. `package.json`).

## 2. Запуск

### Обычный режим

```bash
npm start
```

Эквивалентно `electron .` — запускается приложение без автоматического открытия DevTools.

### Режим разработки

```bash
npm run dev
```

Запускает Electron с флагом `--dev`; в `main.js` при этом открываются **DevTools** главного окна (удобно для отладки UI и консоли рендерера).

### Запуск через batch-файлы

- **`start.bat`** — переходит в папку скрипта, проверяет Node/npm, при необходимости выполняет `npm install`, затем `npm start`.
- **`запуск.bat`** — аналогичная логика.

Если окно консоли сразу закрывается, запустите из уже открытого `cmd`:

```bat
cmd /k "cd /d путь\к\my-browser && start.bat"
```

## 3. Архитектура приложения

Electron разделяет процессы:

| Процесс | Файл | Роль |
|--------|------|------|
| **Главный (main)** | `main.js` | Окно приложения, меню, IPC-сервер, жизненный цикл `app`. |
| **Предзагрузка (preload)** | `preload.js` | Мост: безопасный API `window.electronAPI` для страницы `index.html`. |
| **Рендерер** | `index.html` + `styles.css` + `app.js` | UI: панель, вкладки, `<webview>`, панель AI. |

Страницы сайтов загружаются внутри **`<webview>`** — отдельный процесс рендеринга на базе Chromium, встроенный в окно.

## 5. Интерфейс пользователя

### Верхняя панель (toolbar)

- **← / → / ⟳** — назад, вперёд, обновить активную вкладку.
- **Адресная строка** — URL или произвольный текст:
  - если строка похожа на URL с `http://` или `https://`, открывается как есть;
  - иначе выполняется поиск через Google (`https://www.google.com/search?q=...`).
- **Перейти** — то же, что Enter в поле адреса.
- **🤖** — открыть/закрыть панель AI-ассистента.
- **+** — новая вкладка (стартовый URL задаётся в `app.js`, по умолчанию Google).

### Вкладки

- Клик по вкладке — переключение.
- Кнопка закрытия на вкладке — закрытие (последняя вкладка обычно не закрывается полностью — зависит от реализации в `app.js`).

### Область контента

- В `main` с `id="webviewContainer"` размещаются элементы `<webview>` — по одному на вкладку; активный получает класс `active` и отображается на весь контейнер (см. `styles.css`).

## 6. Вкладки и навигация

Логика находится в **`app.js`**:

- Массив `tabs` хранит объекты с полями `id`, `title`, `url`, ссылкой на DOM-элемент `webview`.
- `activeTabId` — индекс активной вкладки.
- События `did-navigate`, `did-navigate-in-page`, `did-stop-loading` обновляют адресную строку и состояние кнопок «назад/вперёд».

### Горячие клавиши (меню приложения)

Задаются в `main.js` через `Menu.buildFromTemplate`:

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+T` | Новая вкладка |
| `Ctrl+W` | Закрыть вкладку |
| `Alt+Left` | Назад |
| `Alt+Right` | Вперёд |
| `Ctrl+R` | Обновить |
| `Ctrl+Q` | Выход (Windows/Linux) |

События отправляются в рендерер каналами `new-tab`, `close-tab`, `navigate-back`, и т.д.; `preload.js` подписывает на них `electronAPI`.

## 7. AI-ассистент и API

### Назначение

Панель справа позволяет отправлять сообщения в **чат-модель** через HTTP API в формате, совместимом с **OpenAI Chat Completions** (`POST .../chat/completions`).

### Настройки в UI

- **Провайдер:** `DeepSeek` — подставляются заранее заданные URL и модель (см. константы в `app.js`).
- **Custom (OpenAI-compatible)** — вручную указываются **API URL**, **Model** и **API key**.

### Сохранение

Параметры сохраняются в **`localStorage`** браузера Electron (ключи вида `vovanium.assistant.*` — см. объект `STORAGE_KEYS` в `app.js`).

**Важно:** ключ API хранится локально на диске в профиле приложения; не передавайте сборку третьим лицам с вашим ключом.

### Формат запроса

- Заголовки: `Content-Type: application/json`, `Authorization: Bearer <API_KEY>`.
- Тело: JSON с полями `model`, `messages` (включая `system` и историю), `temperature`.

### Типичные ошибки API

| Код / сообщение | Смысл |
|-----------------|--------|
| `401` | Неверный или отозванный API key. |
| `402` / Insufficient Balance | Недостаточно средств на балансе провайдера. |
| `429` | Лимит запросов; подождите. |
| `5xx` | Ошибка на стороне сервера. |

История диалога в `app.js` ограничена последними сообщениями (срез массива), чтобы не раздувать запрос.

### Ограничения

- Запросы идут **напрямую из рендерера** (`fetch`). Для продакшена с секретами лучше проксировать через свой бэкенд.
- CORS: если провайдер не разрешает запросы из `file://` или origin приложения, возможны блокировки — тогда нужен прокси или изменение `webSecurity` (см. раздел безопасности).

## 8. IPC и меню (preload / main)

### preload.js

Экспортирует в `window.electronAPI`:

- `navigate(url)` — отправка URL в main (редко используется напрямую из UI).
- `onNavigate(callback)` — получение `navigate-to` с URL.
- `onNewTab`, `onCloseTab`, `onNavigateBack`, `onNavigateForward`, `onReload` — подписка на действия из меню.

### main.js

- `ipcMain.on('navigate')` пересылает URL обратно в рендерер событием `navigate-to`.

## 9. Настройки Electron (main.js)

### Окно

- Размер по умолчанию: 1200×800.
- Загрузка: `loadFile('index.html')`.

### webPreferences

- `nodeIntegration: false` — Node.js API в странице отключён.
- `contextIsolation: true` — изоляция контекста.
- `preload: preload.js` — единственный контролируемый мост.
- `webviewTag: true` — разрешён тег `<webview>`.
- `webSecurity: false` — **ослаблена** политика same-origin для отладки; в продакшене лучше включить и решать CORS иначе.

### GPU

В коде может быть отключено аппаратное ускорение и добавлен флаг `disable-gpu` для уменьшения артефактов отрисовки `<webview>` на части конфигураций Windows. Если производительность низкая, это можно пересмотреть под ваше железо.

### DevTools

Открываются при `process.argv.includes('--dev')` (скрипт `npm run dev`).

## 10. Безопасность

1. **API-ключи** в `localStorage` — удобно для личного использования, небезопасно для распространённой сборки.
2. **`webSecurity: false`** — упрощает загрузку некоторых ресурсов, но снижает защиту; для публичного релиза включите `webSecurity: true` и настройте прокси для AI.
3. **Контент в webview** — это полноценный браузерный контекст; не открывайте недоверенные URL без понимания рисков.
4. Обновляйте **Electron** при выходе патчей безопасности Chromium.

## 11. Устранение неполадок

### Приложение не запускается

- Проверьте `node -v` и `npm -v`.
- Выполните `npm install` заново.
- Запускайте из каталога проекта: `npm start`.

### Batch-файл сразу закрывается

- Запуск через `cmd /k` (см. раздел [Запуск](#2-запуск)).
- Убедитесь, что путь к проекту без ошибок и Node в `PATH`.

### Страницы не грузятся / пустой экран

- Проверьте сеть и файрвол.
- Откройте DevTools (`npm run dev`) и вкладку Console — ошибки `ERR_*` подскажут причину.

### AI возвращает 402 / «Insufficient Balance»

- Пополните баланс у провайдера или смените ключ/аккаунт.

### AI возвращает CORS или сетевую ошибку

- Некоторые API не разрешают запросы из десктоп-приложения; нужен сервер-прокси или настройка провайдера.

### Некорректная отрисовка страницы (полосы, обрезание)

- Пробовали отключение GPU в `main.js`; при необходимости верните стандартный GPU или обновите драйверы.
- Альтернатива архитектуры — **BrowserView** вместо `<webview>` (требует доработки `main.js`).

## 12. Развитие проекта

Идеи без обязательств:

- Закладки и история (сохранение в `IndexedDB` или файле через IPC).
- Настройки окна и поисковой системы по умолчанию.
- Прокси для AI в main-процессе + скрытие ключей.
- Замена `<webview>` на `BrowserView` для стабильности.
- Тёмная тема, масштаб интерфейса.
- Сборка установщика: `electron-builder` или `electron-forge`.
